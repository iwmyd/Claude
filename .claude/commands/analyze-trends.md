# /analyze-trends — 상위 노출 패턴 분석

입력: $ARGUMENTS

규칙
- **사용자가 직접 붙여넣은 글만** 분석. 검색 결과 자동 수집·크롤링 금지. 네이버 블로그 링크는 WebFetch 하지 말고 본문 붙여넣기 요청.
- 입력이 비어 있으면: "분석할 키워드와, 그 키워드로 검색했을 때 상위(스마트블록/VIEW) 글 3~5편의 제목·본문을 붙여넣어 주세요"라고 요청하고 멈춘다.
- 남의 글 문장을 초안에 옮겨 쓰지 않는다. 구조·패턴만 추출한다.

절차
1. `data/trends.md` 를 읽는다.
2. 글마다 측정: 제목 길이·키워드 위치, 도입 2~3문장 패턴(후킹 유형), 소제목 개수·서브 키워드, 분량(공백 포함), 사진 수(사용자가 알려준 경우), 인용구·구분선 사용, 체크리스트·요약 박스 유무, 마무리·CTA 형태, 협찬 표기 위치.
3. 공통 패턴과 차이점을 정리 → `data/trends.md` 갱신 (분석 이력에 날짜·키워드·글 수, 표본 3개 미만은 "가설").
4. "다음 글에 반영할 것" 3개 이내로 제안 — CLAUDE.md 공식과 충돌하면 충돌 사실을 명시하고 사용자 판단을 묻는다.
