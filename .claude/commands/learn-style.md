# /learn-style — 문체 학습

입력: $ARGUMENTS

규칙
- **사용자가 직접 제공한 본인 글만** 분석한다. 링크를 받으면 네이버 블로그는 WebFetch 하지 말고(도메인 차단 가능) 본문 붙여넣기를 요청한다. 자동 수집·크롤링 금지.
- 입력이 비어 있으면 "본인이 쓴 글 2~5편의 본문을 붙여넣어 주세요"라고 요청하고 멈춘다.

절차
1. `data/style-profile.md`, `data/blogger-profile.md` 를 읽는다.
2. 제공된 글에서 측정: 종결어미 비율(~습니다/~요/~다), 문장 평균 길이, 한 블록 줄 수, 자주 쓰는 표현·접속사, 이모지·기호, 독자 호칭, 도입·마무리 패턴, 인용구 사용 방식.
3. `data/style-profile.md` 를 갱신(학습 이력 표에 날짜·글 수 추가, 근거 예문은 짧게 인용).
4. blogger-profile.md 와 충돌하는 점이 있으면 목록으로 보고하고, 어느 쪽을 따를지 사용자에게 묻는다 (기본은 blogger-profile.md 우선).
5. 다음 /write 에 반영될 변화 3줄 요약.
