# /setup-login — 로그인 세션 설정

1. 사전 확인: `node_modules/playwright` 가 없으면 `npm install` 과 `npx playwright install chromium` 을 먼저 안내·실행한다.
2. 사용자에게 안내: "곧 브라우저가 열립니다. 직접 네이버에 로그인해 주세요(로그인 상태 유지 체크 권장). 저는 아이디·비밀번호를 입력하거나 저장하지 않습니다. 최대 5분 기다립니다."
3. `node scripts/naver_login.js` 실행 (timeout 넉넉히 6분).
4. 결과 확인: `✅ 로그인 세션 저장 완료 — 글쓰기 에디터 진입 확인` 이 출력돼야 성공. 실패면 메시지를 그대로 보여주고 재시도 안내.
5. 주의 안내:
   - `naver-profile/` 폴더는 로그인 세션이다. 외부 공유·업로드·커밋 금지.
   - 브라우저 자동화는 네이버 약관상 회색지대 — 본인 계정, 하루 1~2건 권장.
   - 세션이 만료되면 /setup-login 을 다시 실행.
