# 네이버 블로그 초안 공장

사진 + 소재 정보 + 한줄 메모 → Claude Code 가 사진을 직접 보고 초안 작성 → **승인 후 네이버 임시저장**. 발행은 항상 사람이 합니다.
지침 전체는 [CLAUDE.md](CLAUDE.md).

## 설치 (본인 PC — 브라우저 창이 떠야 하므로 클라우드가 아닌 로컬에서)
```bash
git clone <이 저장소> && cd <폴더>
npm install
npx playwright install chromium
npm test            # 오프라인 모의 테스트 (네이버 접속 없음)
claude              # Claude Code 실행 후
/setup-login        # 열린 브라우저에서 직접 1회 로그인
```

## 사용
1. 사진 → `input/photos/`, 영상(선택) → `input/videos/`
2. `/write 이번 달 바뀌는 청년도약계좌 조건 정리, 협찬 아님` (보도자료 원문도 같이 붙여넣기)
3. 질문에 답 → 초안 검수 보고 확인 → "저장해" → 임시저장 + 자동 검증
4. 평소 쓰는 브라우저/앱에서 "저장 글"을 열어 최종 확인 후 **직접 발행**

기타: `/learn-style`(내 글로 문체 학습), `/analyze-trends`(상위 글 붙여넣어 패턴 분석).

## 주의
- `naver-profile/` 은 로그인 세션 — 외부 공유·커밋 금지.
- 브라우저 자동화는 네이버 약관상 회색지대 — 본인 계정, 하루 1~2건 권장.
- 이 툴은 "초안 공장"이지 "무인 발행기"가 아닙니다.
