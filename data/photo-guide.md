# photo-guide.md — 글 유형별 필수 촬영·캡처 컷

> 경제·시사 블로그는 "현장 사진"보다 "직접 확인한 증거 화면"이 D.I.A.+ 의 경험 신호가 된다.
> 목표 10~15장. 부족하면 /write 검수 보고에서 아래 목록 중 빠진 컷을 추천한다.
> 사진은 **사용자가 직접 찍거나 캡처한 것만**. 사진 재사용 금지.

## ⚠️ 공통 주의
- **저작권**: 언론사 기사 화면·사진, 타 블로그 이미지, 유료 리포트 캡처 금지. 정부 자료는 공공누리 유형 확인(1유형은 출처 표기 후 사용 가능).
- **개인정보 모자이크(mosaic.js)**: 캡처 속 이름·계좌번호·주민번호 앞뒤·전화번호·주소·카드번호·로그인 아이디·QR·바코드, 거리 사진 속 타인 얼굴·차량 번호판. 화자 본인 얼굴도 기본 모자이크.
- 앱·은행 화면 캡처는 잔액·대출금액 등 민감 숫자가 화자 본인 것이어도 공개 의사를 확인한다.

## 유형별 필수 컷
### 생활경제·정책 혜택 (postType: policy)
- ✔ 공고문/보도자료 첫 페이지 (출처·날짜가 보이게)
- ✔ 자격 조건 부분 확대
- ✔ 신청 화면 (정부24·복지로·앱 등) 진입 경로 2~3컷
- ✔ 모의계산기·예상 수령액 결과 화면
- ✔ 필요 서류 목록
- ✔ (가능하면) 신청 완료 화면 — 개인정보 모자이크
- ✔ 직접 정리한 요약 메모·손글씨·화이트보드 (오리지널 이미지 가산)

### 금리·부동산 (postType: rate-realestate)
- ✔ 은행 앱 금리 비교 화면 (날짜 보이게)
- ✔ 대출 계산기 결과 (변경 전/후 2컷)
- ✔ 실거래가·청약홈 화면
- ✔ 현장 사진(단지 외관·모델하우스 등) — 번호판·얼굴 모자이크
- ✔ 공시 그래프는 직접 만든 것만

### 주식·환율·거시경제 (postType: market)
- ✔ 지표 화면(환율·지수) — 시각 표시 포함
- ✔ 환전·해외결제 영수증 등 생활 영향 증거 (개인정보 모자이크)
- ✔ 마트 가격표·주유소 가격판 등 체감 물가 현장
- ✔ 직접 만든 비교 메모/표 사진
- ⛔ 증권사 리포트·유료 차트 캡처

### 사회 이슈·제도 변화 (postType: social)
- ✔ 법령·고시 원문 화면 (국가법령정보센터 등)
- ✔ 시행일·변경 전후 비교 부분
- ✔ 현장 안내문·게시물 (기관 공지 등)
- ✔ 생활 속 변화가 보이는 장면 (안내 스티커, 키오스크 등)

## 동영상 (선택, D.I.A. 가산)
- 신청 과정 화면 녹화 30초~2분 (개인정보 가림) / 현장 짧은 영상.
- input/videos/ 에 넣으면 자동으로 첫 text 블록 직후 삽입. 제목 40자 이내.

## 직접 만든 카드 이미지 (assets/cards/)
- 썸네일·체크리스트·흐름도 같은 요약 카드는 허용 (오리지널 이미지). **글당 최소 4장** (사용자 지시 2026-10-21). 경험 사진이 없으면 카드만으로 게시 가능 — AI로 "직접 찍은 듯한" 사진을 만들지 않는다.
- 외부 이미지: 공공누리 1유형(출처 표기), 상업 이용 가능한 무료 라이선스(Unsplash·Pexels·Pixabay 등 — 라이선스 확인) 만. 출처를 캡션 또는 meta.sources 에 기록.
- 카드에 들어가는 문구도 사실 규칙 동일: 확인 안 된 숫자·날짜·금액 금지. 실제 화면처럼 보이는 그림은 "예시 그림" 표기 필수.
- 실제 기업 로고·화면을 흉내 내지 않는다. 하단 브랜딩: "에이팜의 이야기 보따리".
- 사용할 때는 input/photos/ 로 복사해서 /write 에 쓴다.
