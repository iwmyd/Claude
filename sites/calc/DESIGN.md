# 에이팜 종합계산기 — 디자인 약속 (모든 페이지 공통)

계산기는 "꺼내 쓰는 도구"다. 장식보다 숫자가 먼저 보이고, 손가락으로 누르기 쉬워야 한다.
새 계산기·새 페이지는 아래 약속을 그대로 따른다(페이지마다 새로 고안하지 않는다).

## 색
- 바탕 `--bg` #f8fafc / 카드 `--card` #fff / 글자 `--ink` #0f172a, 보조 `--ink2`, 흐린 글 `--muted` #556274 (흰 바탕 대비 4.5:1 이상)
- 결과 칸 `--soft`: 라이트 #f1f5f9, **다크 #1c2638 (카드보다 한 단계 밝게 — 다크에서 결과가 묻히지 않게)**
- 카테고리·계산기 색(tone)은 `[data-tone]` 한 곳에서만 정의. 색은 아이콘 배경·결과 대표 칸·선택 상태에만 쓴다.
- 금지: 카드 옆·위의 굵은 색 띠, 보라→파랑 그라데이션, 강조색 여러 개를 한 화면에 섞기.

## 글꼴
- 본문 IBM Plex Sans KR, 숫자 IBM Plex Mono — **숫자 글꼴 뒤에 반드시 Plex Sans KR 을 이어서** 한글이 고정폭 대체 글꼴로 벌어지지 않게.
- 숫자 칸은 `font-variant-numeric: tabular-nums`.

## 모양
- 둥글기 3단계: 바깥 상자 `--r-lg` 16px / 카드·타일 `--r` 12px / 입력칸·버튼·칩 `--r-sm` 8px.
- 그림자는 떠 있는 것(검색창, 모바일 하단 요약, 맨 위로 버튼)만. 평평한 상자는 1px 테두리.
- 누르는 것은 모두 높이 44px 이상, 누르면 살짝 작아짐(scale .97).

## 배치
- 홈: 카테고리별 타일. 휴대폰(560px 이하)은 **한 줄에 2개**, 설명 줄 숨김 — "더보기" 없이 전부 한눈에.
- 계산기: 왼쪽 입력, 오른쪽 결과(대표 값 1개 + 보조 값), 아래 그림·표. 휴대폰은 위아래로, 결과가 화면 밖이면 하단 요약 바.
- 제목 줄: 아이콘·제목·즐겨찾기. 휴대폰에서 설명은 아이콘 옆에 끼우지 않고 화면 폭 전체로.

## 글
- 존댓말, 짧은 문장. 버튼·링크 끝에 "→" 붙이지 않기. 느낌표·과장 표현 없이.
- 모든 계산기: 핵심 정리(tips), 계산 기준과 근거(basis·출처), 자주 묻는 질문 3개 이상.

## 검사 (deploy.sh)
계산 테스트 · 브라우저 테스트 · html-validate · axe(라이트·다크) 를 모두 통과해야 배포.
